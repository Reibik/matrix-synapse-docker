# Contributing to Matrix Synapse Docker Setup

Спасибо за интерес к проекту! Мы приветствуем любой вклад.

## Как внести вклад

### 1. Сообщить о проблеме

Если вы нашли баг:
1. Проверьте, нет ли уже похожего Issue
2. Создайте новый Issue с описанием:
   - Версия ОС
   - Шаги для воспроизведения
   - Ожидаемое поведение
   - Фактическое поведение
   - Логи (если есть)

### 2. Предложить улучшение

Есть идея? Создайте Issue с меткой "enhancement" и опишите:
- Какую проблему это решает
- Как это должно работать
- Примеры использования

### 3. Внести изменения в код

#### Процесс

1. **Fork репозитория**
```bash
git clone https://github.com/YOUR_USERNAME/matrix-synapse-docker.git
cd matrix-synapse-docker
```

2. **Создайте ветку**
```bash
git checkout -b feature/your-feature-name
# или
git checkout -b fix/bug-description
```

3. **Внесите изменения**
- Следуйте существующему стилю кода
- Комментируйте сложные части
- Тестируйте изменения

4. **Commit**
```bash
git add .
git commit -m "feat: добавить новую функцию"
# или
git commit -m "fix: исправить баг с SSL"
```

Используйте префиксы:
- `feat:` - новая функция
- `fix:` - исправление бага
- `docs:` - изменения в документации
- `style:` - форматирование, без изменения кода
- `refactor:` - рефакторинг
- `test:` - добавление тестов
- `chore:` - обновление зависимостей и т.д.

5. **Push и Pull Request**
```bash
git push origin feature/your-feature-name
```

Затем создайте Pull Request на GitHub.

## Гайдлайны

### Код

- **Bash скрипты:**
  - Используйте `set -e` для выхода при ошибке
  - Добавляйте комментарии для сложной логики
  - Проверяйте переменные перед использованием
  - Используйте цветной вывод для важных сообщений

- **Docker Compose:**
  - Используйте явные версии образов
  - Добавляйте health checks
  - Документируйте переменные окружения

- **Nginx конфиги:**
  - Следуйте best practices безопасности
  - Комментируйте нестандартные настройки

### Документация

- **README.md** - основная документация
- **QUICKSTART.md** - быстрый старт (краткий)
- **FAQ.md** - частые вопросы
- Пишите на русском (можно перевести на английский позже)
- Используйте примеры кода
- Добавляйте скриншоты где уместно

### Тестирование

Перед созданием PR протестируйте:

1. **Чистая установка:**
```bash
# На новом VPS или в VM
sudo ./install.sh
```

2. **Обновление:**
```bash
docker-compose pull
docker-compose up -d
```

3. **Бэкап/восстановление:**
```bash
./scripts/backup.sh
./scripts/restore.sh
```

4. **Создание пользователя:**
```bash
./scripts/create-user.sh
```

```

├── .env.example            # Шаблон конфигурации

├── README.md              # Главная документация

├── LICENSE                # MIT License

├── nginx/
│   ├── nginx.conf        # Основной конфиг nginx
│   └── matrix.conf       # Конфиг для Matrix
└── scripts/
    ├── create-user.sh    # Создание пользователя
    ├── backup.sh         # Бэкап
    ├── restore.sh        # Восстановление
    ├── status.sh         # Проверка статуса
    └── setup-ssl.sh      # Настройка SSL
```
