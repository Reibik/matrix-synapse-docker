# Matrix Synapse Docker - Информация о проекте

## 📊 Статистика проекта

- **Название:** Matrix Synapse Docker Setup
- **Версия:** 1.0.0
- **Дата создания:** 2026-10-20
- **Лицензия:** MIT
- **Язык:** Bash, Docker Compose, Nginx
- **Платформа:** Ubuntu 22.04 / 24.04

## 🎯 Цель проекта

Предоставить простое и автоматизированное решение для развертывания собственного Matrix Synapse сервера с использованием Docker Compose. Проект рассчитан на пользователей с минимальными знаниями Linux.

## ✨ Особенности

### Автоматизация
- ✅ Автоматическая установка Docker и Docker Compose
- ✅ Автоматическая настройка PostgreSQL
- ✅ Автоматическое получение SSL сертификата через Let's Encrypt
- ✅ Автоматическое создание администратора
- ✅ Проверка DNS перед установкой

### Безопасность
- 🔒 SSL/TLS по умолчанию
- 🔒 PostgreSQL с надежными паролями
- 🔒 Nginx reverse proxy
- 🔒 Изолированная Docker сеть
- 🔒 Health checks для всех сервисов

### Удобство
- 📝 Подробная документация на русском
- 🚀 Установка за 5-10 минут
- 🛠️ Готовые скрипты для управления
- 💾 Автоматические бэкапы
- 📊 Мониторинг статуса

## 📦 Компоненты

### Основные службы
- **Matrix Synapse** - сервер Matrix
- **PostgreSQL 15** - база данных
- **Nginx** - reverse proxy
- **Certbot** - SSL сертификаты

### Вспомогательные скрипты
- `install.sh` - основная установка
- `create-user.sh` - создание пользователей
- `backup.sh` - резервное копирование
- `restore.sh` - восстановление
- `status.sh` - проверка статуса
- `setup-ssl.sh` - настройка SSL
- `update.sh` - обновление Synapse

## 🚀 Быстрое использование

```bash
# 1. Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/matrix-synapse-docker.git
cd matrix-synapse-docker

# 2. Настроить конфигурацию
cp .env.example .env
nano .env

# 3. Запустить установку
sudo ./install.sh

# 4. Готово!
```
